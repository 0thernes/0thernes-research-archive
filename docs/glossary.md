# Glossary (`docs/glossary.md`)

- **Tier I (`PAPERS.json`):** Standalone research preprints with frozen PDFs, Lean 4 formal proofs, and falsification commands.
- **Tier II (`BUILD_PAPERS.json`):** Public engineering builds shipping embedded white papers and Pure Lean 4.35.0 invariant suites.
- **Tier III (`LAWS_AND_DISCOVERIES.json`):** Public architectural laws, pre-registered empirical falsification ledgers, finite certificates, and open-problem atlases.
- **Pinned Git Submodule:** Exact 40-character Git commit SHA under `repos/` verified against `registry/*.json` via `git ls-files --stage repos`.
- **Ten Finding Classes (Build Standard `R7`):** `bug`, `error`, `issue`, `problem`, `concern`, `dilemma`, `conflict`, `gap`, `hole`, `blindspot` (see `.github/labels.tsv` for concise definitions).
