# Contributing

Independent cryptographic verifications, replication reports, broken-link reports, and epistemic-boundary critiques are welcomed via `.github/ISSUE_TEMPLATE/` using the ten Build Standard finding classes (`docs/glossary.md`).

This repository follows Build Standard v1.2.0 solo-maintainer rules (`R1`–`R4`): direct commits to `main`, informational CI, zero PR templates. Run `just reproduce` before committing any registry update.
